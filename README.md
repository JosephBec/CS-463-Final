## About

Personal portfolio website for CS 463 (Intro to Web Development). Single-page site with sections for About, Previous Work, Projects, and Contact.

## Deployed Site

https://JosephBec.github.io/CS-463-Final/

## How to Run

Open `index.html` in a browser, or visit the deployed URL above. No build step or server needed.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5.0.2 (via CDN)

## Outside Sources

- [Bootstrap 5 documentation](https://getbootstrap.com/docs/5.0/) - accordion component, navbar toggler, cards, grid system
- [MDN Web Docs](https://developer.mozilla.org/) - JavaScript references for DOM methods, setTimeout, regex, event handling
- Homework assignments from CS 463 - used as starting points for form structure, image markup, Bootstrap card layout, and DOM event patterns
